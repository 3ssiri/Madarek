قدرات الجيل الثاني من محرك مدارك

قراءة بصرية بنماذج رؤية عربية

موجّه رؤية ذكي (Vision Router) يقرأ الصفحات الممسوحة والصور المعقدة عبر نماذج رؤية محلية (Baseer / Qwen) تعمل دون الحاجة لخدمات سحابية خارجية.

إصلاح النصوص العربية المشوهة

معالجة الحروف المقطوعة والمنعكسة وترتيب الكلمات المعكوس الناتج عن سوء استخراج PDF — المشكلة التي وُلد "مدارك" أساساً لحلها، الآن بمحرك أنضج وأدق.

بحث دلالي هجين (RAG)

كل مستند يُحوَّل إلى معرفة مفهرسة بتضمينات BGE-M3 داخل قاعدة متجهات، فتسأل أرشيفك بالعربية وتحصل على إجابات من قلب مستنداتك.

خادم MCP لوكلاء الذكاء

اربط Claude وغيره من الوكلاء بمعرفتك مباشرة عبر بروتوكول MCP بأدوات جاهزة: بحث دلالي (search)، إدخال مستندات (ingest)، واسترجاع الوثائق (get_document).

خصوصية وكشف البيانات الحساسة

معالجة محلية بالكامل، مع طبقة كشف للبيانات الشخصية (PII) نصياً وبصرياً وأدوات تدقيق دورية تضمن خلوّ قاعدة معرفتك من المعلومات الحساسة.

بنية مؤسسية جاهزة للتوسع

واجهة FastAPI متعددة المستأجرين بمفاتيح API آمنة، ومعالجة غير متزامنة للمهام الثقيلة (Celery + Redis)، وخط أنابيب مرن يتعافى من الأخطاء تلقائياً.

من ملف فوضوي إلى معرفة حيّة

1

الاستلام

ارفع PDF أو صورة عبر الويب، الـ API، أو إضافة Obsidian.

2

الرؤية

الموجّه البصري يختار النموذج الأنسب لقراءة المحتوى.

3

الإصلاح

هيكلة النص العربي وتنقيته وتحويله إلى ماركداون نظيف.

4

الفهرسة

تضمين دلالي وتخزين في قاعدة معرفة (Wiki) قابلة للبحث.

5

الاستثمار

اسأل، ابحث، وادمج معرفتك مع وكلاء الذكاء الاصطناعي.

منظومة متكاملة لكل سيناريو استخدام

واجهة الويب

لوحة تحكم حديثة مبنية بـ Next.js لرفع الملفات ومتابعة المعالجة والبحث في معرفتك.

Madarek API

واجهة برمجية REST مبنية بـ FastAPI مع مفاتيح وصول آمنة ومهام غير متزامنة لخدمة تطبيقاتك.

خادم MCP

وصّل وكلاء الذكاء الاصطناعي بمعرفتك عبر بروتوكول MCP (stdio / SSE) بثلاث أدوات جاهزة.

إضافة Obsidian

أدخل مستنداتك إلى قبو Obsidian مباشرة كملاحظات ماركداون منسقة عبر إضافة مخصصة.

نموذج عربي مخصص

نموذج لغوي مضبوط خصيصاً لإصلاح النصوص العربية (QLoRA) يعمل بسرعة عالية عبر vLLM.

الوحدة التعليمية

EduModule لتحويل المقررات والمستندات التعليمية إلى محتوى منظم قابل للاستذكار والبحث.

ابنِ قاعدة معرفتك العربية اليوم — بخصوصية تامة!

منصة "مدارك 2.0" تعمل بالكامل على بنيتك الخاصة (FastAPI + Next.js + Ollama)، فلا تغادر مستنداتك جهازك أو خوادمك أبداً. النسخة السحابية (Madarek Cloud) بمساحات عمل وحسابات مؤسسية قادمة ضمن خارطة الطريق.
