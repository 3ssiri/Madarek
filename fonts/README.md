# الخطوط — خط ثمانية (Thmanyah Sans)

تستخدم هذه الصفحة **خط ثمانية** (Thmanyah Sans)، وهو خط عربي حديث صادر عن
شركة **ثمانية** (Thmanyah). جميع حقوق الخط محفوظة لأصحابه، ويُستخدم هنا لأغراض
عرض واجهة المشروع.

الملفات بصيغة `woff2` مُحوَّلة من الإصدارات الرسمية لتحسين أداء التحميل على الويب:

| الوزن   | الملف                          |
|---------|--------------------------------|
| Regular | `ThmanyahSans-Regular.woff2`   |
| Medium  | `ThmanyahSans-Medium.woff2`    |
| Bold    | `ThmanyahSans-Bold.woff2`      |
| Black   | `ThmanyahSans-Black.woff2`     |

المصدر: مشروع ثمانية للخطوط — Thmanyah.
